# 防幻觉四铁律：让 Agent 只说实话

> 定位：方法论总纲。沉淀自生产环境 30+ 轮提示词迭代（见 [案例 02](../docs/case-studies/02-xiaou-ai-assistant.md)），抽象为 4 条可复用的工程约束。
> 配套资产：`templates/` 三份落地模板 + `validator.py` 静态校验器（把铁律变成 CI 可检查项）。

---

## 为什么需要铁律

大模型幻觉的三个高发场景，恰好都出现在企业数据助手：

| 场景 | 幻觉表现 | 后果 |
|---|---|---|
| 数值问答 | 编造"当前负荷 75.6MW" | 一线人员按错误数据操作 |
| 报表问答 | 对查询结果做无依据的"异常判断" | 误导运维决策 |
| 知识库问答 | 知识库无答案时自编"据文档记载…" | 知识不可信，产品整体信誉受损 |

**根因只有一个：提示词给了模型自由发挥的空间，却没有给出"不知道时怎么办"的强制路径。**

## 铁律一：未查询，不得断言

**规则**：任何数据类问题，必须先完成工具调用拿到返回值，才允许输出数值结论。回答中出现的每个数值，必须能在对应工具返回值中找到。

**落地写法**：

```text
回答中出现的所有数值，必须来自最近一次工具调用返回值；
未查询到的指标，明确输出「未查询到」，禁止用历史经验或常识补充。
```

**反例**（会出幻觉）：

```text
你可以结合专业知识补充说明当前工况。
```

> "补充说明"四个字就是幻觉的入口——模型会顺着知识库/常识自由发挥。

## 铁律二：写规则，不写死数据

**规则**：提示词只描述"如何获取数据"，不写死任何具体数值、指标名、模型名。数据一律通过 `{{占位符}}` / `{tool_result}` 动态注入，指标列表在运行时从工具返回值匹配。

**落地写法**：

```text
指标列表、单位、量纲一律以工具返回值为准；
用户提到本系统未注册的指标时，反馈「未找到该指标」，并列出可用指标来源。
```

**反例**（会过时/写死）：

```text
本系统常用指标：负荷率、煤耗、主汽温度、给水流量…
```

> 写死指标列表的两个致命问题：① 新指标上线提示词不更新就漏答；② 模型把"列表"当"全集"，列表外的指标直接拒答或编造。**写死的知识一天后就过期，规则十年不过期。**

## 铁律三：没有依据的推断，一个字不写

**规则**：允许给建议，但必须显式区分「数据结论」（来自工具返回值）与「经验建议」（来自模型推理），且经验建议不得伪装成数据结论。

**落地写法**：

```text
输出分两段：
① 数据结论：仅陈述工具返回值，不做好坏评价；
② 建议：以「建议」为前缀输出经验性判断，禁止把建议表述为数据事实。
```

**反例**（数据与推断混淆）：

```text
当前负荷 75.6MW，处于偏高水平，建议降低负荷。
```

> "处于偏高水平"是推断，但和"75.6MW"混在一句里，用户无法区分。真实案例：模型把 75.6MW 的 75.6% 负荷率误判为"异常偏高"，只因提示词没约束推断边界。

## 铁律四：引用来源，让答案可回溯

**规则**：知识库类回答必须标注来源文档；数值类回答标注来源接口/测点；无来源时明确声明。

**落地写法**：

```text
引用知识库内容时，以「[来源] 文档名/章节」标注；
数值来自实时接口时标注「（实时）」，来自报表接口时标注「（报表，统计周期）」。
```

**反例**：

```text
据运维手册记载，凝汽器真空应在 -90kPa 以上。
```

> 不写来源 = 无法验证 = 无法追责。写出来源后，哪怕答案错了也能快速定位是哪份文档、哪条链路的问题。

## 校验器：把铁律变成机器检查

文字规则会被人遗忘，**校验器不会**。`validator.py` 把四条铁律转成可自动执行的检查项，纳入 CI 后每次改提示词都能自动拦截"写死数据"的回归：

| 铁律 | 校验项 | 检查方式 |
|---|---|---|
| 铁律二 | 模板正文不得出现裸数字（阈值/百分比/固定参数） | 正则扫描非代码块正文 |
| 铁律二 | 模板不得写死业务实体名（指标名/模型名） | 黑名单 + 自定义词表 |
| 铁律一/三 | 规则句必须引用动态占位符（`{{...}}` 或 `{tool_...}`） | 占位符数量检查 |
| 铁律四 | 模板必须包含防幻觉核心约束（不得编造/未查询不得断言/引用来源） | 关键词命中检查 |

运行方式：

```bash
python validator.py                # 扫描 templates/ 全部模板
python validator.py -f 指定文件     # 扫描单个文件
python validator.py --ci           # CI 模式：有警告即非零退出
```
